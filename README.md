# Warehouse Inventory App

A full-stack Android application for warehouse inventory management.

## Features

- Create, edit and delete products.
- Manage stock across multiple warehouses.
- Scan EAN/QR codes using the device camera.
- Upload and manage product images.
- Search, sort and filter inventory.
- Infinite scrolling with pagination.

## Architecture

- Android App -> REST API -> Ktor Backend -> PostgreSQL
